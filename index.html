ICT Glossaries

HTML
HyperText Markup Language used to create and structure webpages.
CSS
Cascading Style Sheets used to design and style webpages.
CPU
Central Processing Unit that processes instructions and performs calculations in a computer.
RAM
Random Access Memory that temporarily stores data used by the computer.
URL
Uniform Resource Locator, which is the address used to access a resource on the internet.

Frequently Asked Questions

What is ICT?
ICT stands for Information and Communication Technology. It involves technologies used to create, store, process, and communicate information.
What is HTML used for?
HTML is used to create and structure the content of webpages.
What is CSS used for?
CSS is used to control the appearance, colors, fonts, and layout of webpages.
What is a computer?
A computer is an electronic device that processes data and performs various tasks.
